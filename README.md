# Undergraduate Thesis Source

This repository preserves the LaTeX source for Matheus Kunzler Maldaner's 2025 University of Florida undergraduate thesis on Differentiable Logic Gate Networks. The earliest preserved Git snapshot was imported after thesis acceptance, and later commits may contain formatting or editorial changes.

## Reproducibility archive

The retrospective artifact recovery, accuracy review, provenance records, errata, and executable checks are available in the public [Undergraduate Thesis Reproducibility Archive](https://github.com/matheusmaldaner/UndergradThesis).
